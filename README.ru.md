# Диктофон для занятий

[English](README.md) · **Русский**

Простой офлайн-диктофон для занятий с логопедом. Одна большая кнопка ведёт весь
цикл: **нажал — пошла запись, нажал — остановилась, нажал — пошло
воспроизведение**. Дубль не сохраняется в файлы, пока вы не нажмёте
«Сохранить», а новая запись сразу стирает предыдущую.

## Зачем

Для занятий по постановке голоса и речи нужен «черновик»: записал фразу,
послушал, перемотал, попробовал снова. Промежуточные дубли не должны засорять
галерею, а новая попытка должна начинаться в один тап. Поэтому:

- всё пишется во временный кэш приложения и не попадает в файлы;
- «Новая запись» стирает предыдущий дубль без подтверждений;
- в файл сохраняется только то, что вы решили оставить, и только по кнопке.

## Возможности

- запись голоса одной кнопкой (микрофон, AAC 44,1 кГц, 128 кбит/с, моно);
- остановка записи той же кнопкой;
- воспроизведение и пауза той же кнопкой;
- перемотка по шкале в любую точку, воспроизведение продолжается после
  перетаскивания;
- живая «дорожка» амплитуды и таймер;
- «Новая запись» — стирает текущий дубль и сразу начинает новый;
- «Сохранить» — отдельная кнопка, кладёт `.m4a` в «Музыка/Диктофон»;
- экран не гаснет, пока приложение открыто;
- пауза при отключении наушников и при потере аудиофокуса;
- тёмная тема, крупные элементы под палец, без рекламы и интернета.

## Установка

1. Скачайте `dictaphone-1.0.apk` из [последнего релиза](../../releases/latest).
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. При первом нажатии на запись приложение попросит доступ к микрофону.

Требуется Android 10 (API 29) или новее. Приложение ничего не отправляет в сеть.

## Сборка

```bash
export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # подписанный app/build/outputs/apk/release/app-release.apk
```

Нужен Android SDK с платформой 36 и JDK 21. Путь к SDK — в `local.properties`
(`sdk.dir=...`) или через переменную `ANDROID_HOME`.

CI (GitHub Actions, `.github/workflows/build.yml`) собирает оба APK на каждый
пуш и прикладывает подписанный APK к релизу по тегу `v*`.

Ключ подписи `app/dictaphone.jks` (alias и пароль `dictaphone`) лежит в
репозитории — это личный инструмент, не публикация в маркете.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `MainActivity.java` | состояние экрана (ожидание → запись → готово → воспроизведение), запись через `MediaRecorder`, прослушивание через `MediaPlayer`, сохранение в `MediaStore` |
| `WaveformView.java` | отрисовка дорожки амплитуды и прогресса прослушивания |
| `res/layout/activity_main.xml` | экран: таймер, статус, дорожка, шкала перемотки, главная кнопка, «Новая запись» / «Сохранить» |

Временный файл — `cacheDir/session.m4a`. Он удаляется при новой записи и при
закрытии экрана. Сохранение копирует его в `MediaStore` (`Music/Диктофон`).

Ограничение: запись идёт без foreground-service, поэтому при уходе в другое
приложение на Android 14+ микрофон может быть приглушён. Во время записи экран
остаётся включённым.
